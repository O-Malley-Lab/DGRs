# DGRs
Code and sequencing data from DGR project

Raw sequencing files: .fastq
Metadata-DGRs2023.xlsx contains info on which raw sequencing files correspond to which strains and conditions.

For each strain, there is a -job.txt file containing all the code used for that strain. 
Within the code, there is a -position.txt file needed which is uploaded here, as well as a .fasta reference file for each strain.

There is also the python file for the calc_pi_from_pileup_v1.py used within the strain code files.

Relevant publication: Natural genetic variation caused by diversity-generating retroelements decreases as rumen bacteria are isolated and cultured. A. R. Eisenberg, S. Seagrave, H. Doré, K. Luttrell, A. Ganesh, B. G. Paul, X. Peng, E. G. Wilbanks, D. L. Valentine, M. A. O’Malley.
